# 급여·청구 계산 규칙

## 실제 자료에서 확인한 흐름

1. 직무별 급여표에서 기본급, 식대, 고정수당과 법정수당을 불러온다.
2. 월 기준일수 대비 실제 근무일수로 기본급·식대를 일할 계산한다.
3. 통상시급은 `(기본급 + 식대) / 209`를 10원 단위 올림 처리한다.
4. 연장·휴일근로는 통상시급의 150%, 야간근로는 50%를 적용한다.
5. 보험·세금·복리후생·수수료·이윤을 더해 고객사 공급가를 계산한다.
6. 공급가를 십원 단위 처리한 후 부가세 10%와 청구 합계를 계산한다.

`scripts/payroll-engine.mjs`는 기존 청구 원본 수식의 계산 순서와 반올림 단위를 재현하는 검증용 코드다.

## Phase 3 — 근로자 급여 계산

운영 프로그램의 월 급여는 고객사 청구와 분리한다.

### 자동 입력

- 급여월의 유효 배치 근로자
- 직무·지점·적용기간에 맞는 급여기준
- 결근·무급·휴직 일수
- 연장·휴일·야간 시간

### 계산

- 기본급 일할: `기본급 × 근무일수 / 월 기준일수`
- 식대 일할: `식대 × 근무일수 / 월 기준일수`
- 통상시급: `(기본급 + 식대) / 209`, 10원 단위 올림
- 연장수당: `통상시급 × 1.5 × 연장시간`
- 휴일수당: `통상시급 × 1.5 × 휴일시간`
- 야간수당: `통상시급 × 0.5 × 야간시간`
- 지급총액: 일할 기본급·식대 + 고정수당 + 법정수당 + 연차수당 + 인센티브 + 소급 + 기타지급 - 기타공제 + 수동조정

### 확인필요 처리

다음 항목은 자동 확정하지 않는다.

- 급여기준이 연결되지 않은 근로자
- 입사월 또는 퇴사월로 실제 급여 산정 근무일수 확인이 필요한 근로자
- 수동조정 금액이 있으나 조정사유가 없는 항목

`확인필요`가 남아 있는 급여회차는 승인 또는 마감할 수 없다.

### 현재 자동화하지 않는 항목

근로자 개인의 국민연금·건강보험·장기요양·고용보험·소득세·지방소득세 공제는 현재 확보된 원본 근거만으로 정확한 자동 산식이 확정되지 않았으므로 Phase 3에서 임의 계산하지 않는다.

## Phase 4 — 고객사 청구

회사 부담 보험료·부담금·복리후생비·사고충당금·관리비·수수료·이윤·VAT 등은 근로자 급여와 별도의 고객사 청구 계산으로 구현한다.

## 반드시 확인할 항목

원본 급여표에서 산재보험·고용보험 등 일부 항목의 셀 요율과 설명 문구가 서로 다르다. 프로그램은 이를 임의로 고치지 않고 실제 마감 전에 담당자가 적용 값과 시행 기간을 확정해야 한다.
