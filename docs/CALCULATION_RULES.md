# 급여·청구 계산 규칙

## 실제 자료에서 확인한 흐름

1. 직무별 급여표에서 기본급, 식대, 고정수당과 법정수당을 불러온다.
2. 월 기준일수 대비 실제 근무일수로 기본급·식대를 일할 계산한다.
3. 통상시급은 `(기본급 + 식대) / 209`를 올림 처리한다.
4. 연장·휴일근로는 통상시급의 150%, 야간근로는 50%를 적용한다.
5. 보험·세금·복리후생·수수료·이윤을 더해 공급가를 계산한다.
6. 공급가를 십원 단위 처리한 후 부가세 10%와 청구 합계를 계산한다.

`scripts/payroll-engine.mjs`는 원본 수식의 계산 순서와 반올림 단위를 재현하고 테스트한다.

## 반드시 확인할 항목

원본 급여표에서 산재보험·고용보험 등 일부 항목의 셀 요율과 설명 문구가 서로 다르다. 프로그램은 이를 임의로 고치지 않고 적용연도별 규칙을 `needs_review` 상태로 가져온다. 실제 마감 전에 담당자가 적용 값과 시행 기간을 확정해야 한다.
