# 한성자동차 관리프로그램

한성자동차 파견인력 운영을 **Excel 없이 프로그램 안에서 처리하기 위한 내부 웹 시스템**입니다.

## 제품 원칙

- 기존 Excel·Word·PDF는 과거 업무 분석과 최초 1회 데이터 이전을 위한 참고자료입니다.
- 실사용 전환 후 인력, 지점, 직무, 배치, 계약, 근태, 연차, 급여, 청구의 기준 원본은 프로그램 DB입니다.
- 매월 Excel을 업로드하거나 Excel을 먼저 수정한 뒤 프로그램에 반영하는 운영 방식은 사용하지 않습니다.
- Excel/PDF는 필요할 때 제출·보고용으로 **내보내기**만 지원하는 방향으로 개발합니다.

## 현재 개발 단계

### Phase 1 — 핵심 운영 기반

- 인력 신규 등록·수정·상태 관리
- 지점·직무 마스터 및 적용기간별 급여기준
- 지점·직무 배치와 최초·연장·변경 계약 이력
- 인력 상세 및 검색·필터
- 관리자/운영자 2인 권한을 위한 데이터 구조와 감사로그 기반

### Phase 2 — 근태·연차·대체근무

- 정상근무는 자동 전제로 두고 연장·야간·휴일·결근·무급·휴직 등 예외만 기록
- 연차를 발생·사용·조정·취소·만료·퇴사정산 원장으로 관리
- 대체근무 요청 → 경험 기반 후보 추천 → 배정 → 완료 및 이력 누적

### Phase 3 — 월 급여

- 월별 급여 회차 생성
- 해당 월 배치 근로자 자동 대상 생성
- 직무·지점·적용기간에 맞는 급여기준 연결
- 결근·무급·휴직 일수와 연장·휴일·야간시간을 근태에서 자동 집계
- 기본급·식대 일할, 통상시급, 연장·휴일·야간수당 계산
- 연차수당·인센티브·소급·기타지급·기타공제·수동조정 입력
- 직원별 계산 근거 확인 및 재계산
- `작성중 → 검토 → 승인 → 마감` 상태 관리
- 급여기준 미연결 또는 입·퇴사 월은 자동으로 `확인필요` 처리
- `확인필요`가 남아 있으면 승인·마감 차단
- 마감 후 급여 수정 차단

이번 Phase 3의 자동 계산 범위는 **근로자 지급 총액**까지입니다. 근로자 개인 4대보험·소득세·지방소득세 공제는 원본 근거가 확정되지 않은 상태에서 임의로 계산하지 않습니다. 회사 부담 보험료·간접비·수수료·VAT 등 한성자동차 고객사 청구는 Phase 4에서 급여와 분리해 구현합니다.

이후 단계:

1. Phase 4: 한성자동차 청구·퇴사정산
2. Phase 5: 로그인·권한·문서·내보내기·무료 배포

## 기술 구성

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- 개발/로컬 검증: Node.js SQLite
- 최종 무료 배포 DB는 배포 단계에서 Cloudflare 환경에 맞춰 확정

## 실행

```powershell
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`으로 접속합니다.

프로그램은 `data/local/hansung.sqlite`를 자동 생성하고 운영 스키마를 적용합니다. 해당 DB에는 개인정보·급여정보가 포함될 수 있으므로 Git에서 제외됩니다.

## 기존 실제 데이터의 최초 1회 전환

기존 `data/local/hansung.sqlite`에 실제 데이터가 이미 있다면 Excel을 다시 읽지 않습니다.

```powershell
npm run migration:operational
npm run migration:phase2
```

- `migration:operational`: 기존 인력·지점·직무·배치를 운영 테이블로 1회 이전
- `migration:phase2`: 기존 대체인력·근무이력을 새 대체근무 구조로 1회 이전

급여회차는 과거 Excel을 다시 가져오지 않고 프로그램의 현재 운영 DB에서 새로 생성합니다.

## 기존 자료 분석용 레거시 도구

아래 명령은 **매월 사용하는 운영 기능이 아닙니다.** 기존 Excel 분석을 다시 검증해야 하는 특별한 경우에만 사용합니다.

```powershell
npm run data:import -- --source="C:\Users\hansuk\Desktop\한성자동차\한성자동차 관리프로그램\doc"
npm run data:validate
npm run data:summary
```

최종 데이터 이전이 끝나면 일상 업무에서는 이 명령을 사용하지 않습니다.
